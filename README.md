# 🏡 Design Your Home — Single Page Interior Design Website

A modern, responsive single-page interior architecture and home design website built with pure HTML5 and CSS3. Features a glassmorphic sticky navigation bar, a full-screen hero banner, curated showcase cards for every living area, and smooth in-page anchor navigation.

---

## Features

- **Glassmorphic Sticky Navigation**: Fixed navigation bar with `backdrop-filter: blur(12px)` and smooth anchor links.
- **Hero Showcase Header**: Full-viewport banner featuring high-resolution architectural photography, elegant serif typography, and call-to-action buttons.
- **Alternating Space Showcase Cards**: Responsive two-column grid cards alternating between image and narrative for Bedroom, Dining, Kitchen, and Backyard spaces.
- **Curated Visual Assets**: High-resolution interior architecture photography loaded via Unsplash CDN.
- **Smooth Anchor Scrolling**: Seamless page transitions enabled by native `scroll-behavior: smooth`.
- **Mobile Responsive Layout**: Fluid CSS Grid and Flexbox system designed for mobile, tablet, and desktop screens.
- **Zero Dependencies**: Pure HTML5 and CSS3 without external frameworks or JavaScript runtime requirements.

## Getting Started

No build tools, package managers, or server installations are necessary.

### 1. Clone the repository

```bash
git clone https://github.com/Kumar44developer/Single-page-Website-Using-HTML-CSS-.git
```

### 2. Launch the website

Open `index.html` directly in any web browser, or serve it using an extension like VS Code Live Server.

---

## Customization

- **Change Photography**: Update the background image URLs in `index.html` within each `.space-image` inline style.
- **Modify Accent Colors**: Update the warm gold accent color (`#e0a96d`) in `style.css` to match your brand theme.
- **Add New Space Sections**: Copy a `.space-section` block in `index.html` and add corresponding navigation links in `#navbar`.
