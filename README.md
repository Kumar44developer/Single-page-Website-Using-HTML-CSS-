# Design Your Home

A responsive single-page interior design website built with plain HTML5 and CSS3. It presents a luxury home-design brand through a full-screen hero, alternating showcase sections for each living space, and a glassmorphic sticky navigation bar.

## Overview

The site is a static front-end project with no build step, no frameworks, and no JavaScript. It demonstrates modern layout techniques such as CSS Grid, Flexbox, backdrop blur, and smooth anchor scrolling, styled with a warm dark theme and premium typography.

## Features

- Fixed glassmorphic navigation bar with smooth in-page anchor links
- Full-viewport hero banner with headline, description, and call-to-action buttons
- Four alternating showcase sections: Bedroom, Dining, Kitchen, and Backyard
- Fully responsive layout for mobile, tablet, and desktop
- Google Fonts pairing (Playfair Display and Outfit) and Font Awesome icons
- No dependencies or build tools required

## Tech Stack

| Technology | Role |
| --- | --- |
| HTML5 | Semantic structure and section landmarks |
| CSS3 | Grid, Flexbox, glassmorphism, transitions, and media queries |
| Google Fonts | Typography |

## Getting Started

Clone the repository and open the page in any browser. No installation is required.

```bash
git clone https://github.com/Kumar44developer/Single-page-Website-Using-HTML-CSS-.git
```

Open `index.html` directly, or serve the folder with a tool such as VS Code Live Server for live reloading.

## Customization

- Replace the Unsplash background image URLs inside each `.space-image` element in `index.html`
- Adjust the gold accent color `#e0a96d` in `style.css` to change the theme
- Duplicate a `.space-section` block and add a matching navigation link to introduce a new space
